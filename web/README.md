# Pic2Pic Web UI - Vue3 + Vite 版本

这是 Pic2Pic 项目的重构前端，使用 Vue3 + Vite 构建，提供了更好的用户体验和功能。

## 新功能特性

### 🎨 增强的画布组件
- **缩放功能**: 支持画布缩放（25% - 300%）
- **快捷键支持**: 
  - `B` - 切换到画笔模式
  - `E` - 切换到橡皮擦模式
  - `Ctrl+Z` - 撤销
  - `Ctrl+0` - 重置缩放
  - 鼠标滚轮 - 缩放画布
- **画笔大小调节**: 可调节画笔大小（1-50）
- **历史记录**: 支持最多50步撤销
- **图片上传**: 支持上传图片到画布
- **下载功能**: 一键下载画布内容

### 🎛️ 改进的控制面板
- **双模式切换**: 基础模式和高级模式
- **响应式布局**: 自适应不同屏幕尺寸
- **实时预览**: 参数变更时自动触发预览
- **质量预设**: 内置多种质量预设（Noob/Normal/Hardcore/God）

### 🎭 风格和 LoRA 选择器
- **8种预设风格**: 动漫、写实、油画、水彩、赛博朋克、奇幻、极简、复古
- **一键切换**: 点击即可应用风格到提示词
- **LoRA 支持**: 4种 LoRA 模型可选
- **权重调节**: 可调节 LoRA 权重（0-1）

### 📊 进度条组件
- **实时进度显示**: 显示生成进度百分比
- **阶段提示**: 显示当前生成阶段
- **动画效果**: 流畅的进度动画
- **详细信息**: 显示当前处理状态

### 🔧 技术特性
- **Vue3 Composition API**: 使用最新的 Vue3 特性
- **Pinia 状态管理**: 统一的状态管理
- **Axios HTTP 客户端**: 优化的 API 请求
- **响应式设计**: 适配桌面和移动设备
- **组件化架构**: 模块化、可维护的代码结构

## 开发环境设置

### 前置要求
- Node.js 16+ 
- npm 或 yarn
- 后端服务器运行在 http://127.0.0.1:5000

### 安装依赖
```bash
cd web
npm install
```

### 启动开发服务器
```bash
npm run dev
```

开发服务器将在 http://localhost:5173 启动

### 构建生产版本
```bash
npm run build
```

构建后的文件将输出到 `dist` 目录

## 组件说明

### CanvasComponent
画布组件，提供绘图功能：
- 画笔/橡皮擦模式切换
- 画笔大小调节
- 缩放功能
- 撤销/重做
- 图片上传和下载

### ControlPanel
控制面板，提供参数设置：
- 提示词输入
- 负面提示词输入
- 画布尺寸设置
- 随机种子生成
- 输出格式选择
- 基础/高级模式切换

### StyleSelector
风格选择器，提供风格和 LoRA 选择：
- 8种预设风格
- LoRA 模型选择
- 权重调节
- 一键清除

### PreviewPanel
预览面板，显示生成结果：
- Stage 1 预览
- Canny 边缘检测
- 最终结果
- 下载功能

### ProgressBar
进度条组件，显示生成进度：
- 进度百分比
- 阶段提示
- 动画效果

## API 集成

前端通过 Vite 代理与后端 API 通信：

```javascript
// API 端点
GET  /api/status     # 获取服务器状态
POST /api/preview    # 生成预览
POST /api/generate   # 生成图像
```

## 开发注意事项

1. **后端依赖**: 确保后端服务器在 5000 端口运行
2. **代理配置**: Vite 配置了代理到后端的 API 请求
3. **热重载**: 开发模式下支持热重载
4. **环境变量**: 可通过 `.env` 文件配置环境变量
